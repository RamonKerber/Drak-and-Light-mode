# 🚲 Bikcraft — Landing Page

Projeto de uma landing page responsiva para uma marca fictícia de bicicletas elétricas, desenvolvido como parte dos meus estudos de Front-End, com base no curso da Origamid.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- CSS Grid e Flexbox
- Media Queries
- Modo claro e escuro com CSS

## ✨ Funcionalidades

- Layout responsivo para desktop e dispositivos móveis
- Design moderno e adaptável
- Suporte aos temas claro e escuro conforme a preferência do sistema

## 📚 Objetivo

Praticar HTML semântico, estilização com CSS, responsividade e organização de layouts.
